# Monetiza Restaurante

Feito em dez/2023, na faculdade. Está aqui como arquivo: o código ficou do jeito que era na época.

Jogo mobile de lanchonete com joystick virtual. Cada missão sorteia os ingredientes do lanche (pão, carne, queijo, alface, tomate), e você precisa preparar a carne na bancada e montar o prato antes do tempo acabar. Tem menu, gameplay e game over.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.17f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

## Créditos

Joystick Pack (Asset Store) e o pacote de arte em `Assets/Monetiza Restaurante`.
